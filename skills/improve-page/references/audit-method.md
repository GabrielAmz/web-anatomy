# Web Anatomy Audit Method

Use this method to compare a current page or section against benchmark examples without exposing internal scores.

## 1. Start With Current Reality

Write down what is actually visible:

- page archetype and likely traffic intent
- headline, subheadline, CTA text, secondary CTA
- visible proof: logos, customer names, metrics, testimonials, security, press
- product evidence: UI screenshot, workflow, output, demo, before/after
- hierarchy: what dominates, what is buried, what appears above the fold
- friction: vague category, weak CTA, missing proof, competing actions, unclear risk

If you cannot inspect the page, do not pretend. Ask for URL, screenshot, pasted copy, or switch to market-pattern guidance.

## 2. Route To The Right Benchmark Set

Match by priority:

1. section type
2. page archetype
3. industry
4. buyer intent
5. visible pattern

Do not overfit to industry if the section pattern is universal. Pricing pages, testimonial blocks, and CTA bands often transfer well across adjacent B2B categories.

## 3. Compare Only Useful Dimensions

Hero:

- category clarity
- outcome specificity
- audience specificity
- CTA clarity
- proof proximity
- product visual
- risk reduction
- above-the-fold hierarchy

Pricing:

- plan differentiation
- default or recommended plan
- annual/monthly choice architecture
- trial/demo path
- objection handling
- enterprise path
- surrounding proof

Testimonials:

- named person
- title and company credibility
- quantified outcome
- before/after specificity
- photo, logo, or video support
- relevance to the target buyer

Trust:

- logo relevance
- proof density
- security/compliance
- metric specificity
- proximity to conversion action

Features:

- benefit translation
- product screenshot evidence
- use-case grouping
- information hierarchy
- scanability

CTA:

- action specificity
- motivation
- risk reduction
- visual prominence
- consistency with hero CTA

FAQ:

- real objections
- answer specificity
- pricing/migration/security coverage
- useful links to docs or sales paths

## 4. Use Public Gap Labels

- `HIGH`: likely blocks comprehension, trust, or conversion.
- `MEDIUM`: meaningful improvement opportunity.
- `LOW`: polish or optional optimization.

Keep internal benchmark scores, thresholds, angle counts, field names, and marker coordinates out of the report.

## 5. Make The Fix Concrete

Every recommendation should say:

- what to add
- what to remove
- what to rewrite
- what proof to surface
- what visual hierarchy to change
- which benchmark pattern inspired the direction

Weak: "Make the hero clearer."

Strong: "Move one named customer quote above the first scroll, directly under the hero CTA, so the buyer sees proof before deciding whether to book a demo."
