# Matching Method

Use this ladder when selecting examples:

1. exact section type
2. same page archetype
3. same industry
4. adjacent industry with the same buyer intent
5. visible pattern match
6. named static reference fallback

For research reports, run several query angles before synthesizing:

- exact section or archetype
- section plus industry
- section plus competitor
- adjacent section type
- broad market examples

Group findings by repeatable pattern. Never turn the report into a ranked list of companies.
